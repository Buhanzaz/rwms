# RWMS Manager for Android

Приложение руководителя работает только через публичный origin API gateway и
использует существующие учётные записи RWMS.

Допускаются пользователи с ролями `SYSTEM_ADMIN`, `WMS_ADMIN` и
`WAREHOUSE_MANAGER`, которым администратор включил доступ к приложению в
настройках пользователей. OAuth-клиент `rwms-manager-android` использует
Authorization Code, PKCE S256 и ротацию refresh-токенов. Токены шифруются
неэкспортируемым ключом Android Keystore.

## Сборка

По умолчанию используется демонстрационный HTTPS gateway. Другой gateway
задаётся только как абсолютный HTTPS origin:

```bash
ANDROID_HOME=/root/Android/Sdk \
  ./gradlew -PRWMS_PUBLIC_BASE_URL=https://rwms.example.test assembleDebug
```

В приложение не передаются адреса внутренних сервисов. Все запросы идут на
same-origin маршруты `/auth/**` и `/api/**`.

Сервер остаётся единственным владельцем инвентаризаций, возвратов, смет,
ремонтов и истории. На устройстве сохраняются только зашифрованная OAuth-сессия
и последний выбранный серверный UUID склада.

Камера использует CameraX 1.6.1. Фотографии сохраняются напрямую в JPEG или,
когда это поддерживает устройство, JPEG Ultra HDR; видео — в MP4. Android не
декодирует и не пережимает готовый файл перед загрузкой. Благодаря этому
EXIF-ориентация фотографии доходит до `media-service`, который применяет её
при создании канонического изображения. Физический поворот телефона
отслеживается независимо от заблокированной ориентации экрана; если прошивка
камеры сохраняет недопустимый EXIF `Orientation=0`, приложение исправляет тег
до загрузки без декодирования и повторного сжатия снимка. Ночной OEM-профиль,
HDR-расширение,
Ultra HDR,
доступные мегапиксели, качества видео, частота кадров и диапазон зума всегда
определяются по возможностям выбранной камеры. Приложение перечисляет также
доступные Android физические сенсоры логической задней камеры и закрепляет
каждый поток за выбранным сенсором, поэтому широкоугольный объектив появляется
отдельной позицией, а выбор 40+ MP
переключает съёмку на сенсор, который реально публикует этот JPEG-режим.
Клавиши увеличения и уменьшения громкости работают как физический затвор.

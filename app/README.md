# RWMS Manager for Android

Приложение руководителя работает только через публичный origin API gateway и
использует существующие учётные записи RWMS.

Допускаются пользователи с ролями `SYSTEM_ADMIN`, `WMS_ADMIN` и
`WAREHOUSE_MANAGER`, которым администратор включил доступ к приложению в
настройках пользователей. OAuth-клиент `rwms-manager-android` использует
Authorization Code, PKCE S256 и ротацию refresh-токенов. Токены шифруются
неэкспортируемым ключом Android Keystore.

## Сборка

По умолчанию используется демонстрационный HTTPS gateway. Другой gateway
задаётся только как абсолютный HTTPS origin:

```bash
ANDROID_HOME=/root/Android/Sdk \
  ./gradlew -PRWMS_PUBLIC_BASE_URL=https://rwms.example.test assembleDebug
```

В приложение не передаются адреса внутренних сервисов. Все запросы идут на
same-origin маршруты `/auth/**` и `/api/**`.

Сервер остаётся единственным владельцем инвентаризаций, возвратов, смет,
ремонтов и истории. На устройстве сохраняются только зашифрованная OAuth-сессия
и последний выбранный серверный UUID склада.

Камера использует CameraX 1.6.1. Снятые и выбранные из галереи JPEG Android
приводит к физически правильной ориентации до помещения в очередь загрузки и
записывает EXIF `Orientation=1`; при нормализации очень большого кадра размер
ограничивается 13 МП, чтобы не исчерпать память телефона. Видео сохраняется в
MP4. JPEG Ultra HDR не используется: gain map нельзя надёжно сохранить после
такого преобразования пикселей. `media-service` хранит и строит варианты из
переданного клиентом изображения, не применяя EXIF или запрошенный серверный
поворот. Физический поворот телефона отслеживается независимо от заблокированной
ориентации экрана. Ночной OEM-профиль, HDR-расширение, доступные мегапиксели,
качества видео, частота кадров и диапазон зума всегда определяются по
возможностям выбранной камеры. Приложение перечисляет также доступные Android
физические сенсоры логической задней камеры и закрепляет каждый поток за
выбранным сенсором, поэтому широкоугольный объектив появляется отдельной
позицией, а выбор 40+ MP переключает съёмку на сенсор, который реально
публикует этот JPEG-режим. Клавиши увеличения и уменьшения громкости работают
как физический затвор.

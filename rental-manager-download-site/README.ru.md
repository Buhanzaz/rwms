# Запись релиза Rental Manager

Этот каталог владеет метаданными APK Rental Manager и политикой подписи для
общей страницы [Downloads](../downloads-site/README.ru.md). APK и отдельной
посадочной страницы здесь нет. Артефакты раздаются из
`/var/www/rwms-rental-manager-download/` по неизменяемым URL версий.

Первый канал — `INTERNAL_TEST`, пакет
`dev.buhanzaz.rwms.rentalmanager.debug`, с существующим Android debug
сертификатом. Запись `pending` не заявляет контрольную сумму артефакта или дату
публикации. Статус `published` устанавливается после сборки и проверки самого APK.

Команда `npm run check` проверяет запись и политику подписи. Для опубликованной
записи задайте `RWMS_RENTAL_MANAGER_APK` с путём к проверенному локальному APK;
проверяются пакет, версия, SHA-256 и сертификат подписи.
